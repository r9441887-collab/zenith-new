# STM32 режим (микроконтроллеры)

Zenith умеет компилировать прошивки для микроконтроллеров STM32
(ARM Cortex-M, набор инструкций Thumb/Thumb-2). Выход — плоский бинарный
образ `.bin`, который зашивается во флеш по адресу `0x08000000`
(ST-Link, QEMU и т.п.). Работает без внешних зависимостей: весь код и
данные — это вектор прерываний + код + строковые константы.

## Тип приложения

```zenith
app stm32
mcu: stm32f103     # необязательно (по умолчанию stm32f103)
led_pin: PC13      # необязательно (по умолчанию PC13)
sysclk: 72000000   # необязательно (HCLK в Гц, калибрует delay_ms)
```

| Директива | Значение | По умолчанию |
|-----------|----------|--------------|
| `mcu:` | Семейство чипа: `stm32f4*` / `stm32f7*` — GPIO AHB1 и 128 КБ SRAM; `stm32l4*` — GPIO AHB2 и 128 КБ SRAM; `stm32g0*` — Cortex-M0+ и 32 КБ SRAM; остальные (F1) — F1-стиль и 20 КБ SRAM | `stm32f103` |
| `led_pin:` | Пин бортового светодиода, которым мигает `print()` | `PC13` |
| `sysclk:` | Тактовая частота HCLK в Гц, используется для калибровки `delay_ms()` и бит-бангового UART | `72000000` |
| `sram_kb:` | Размер SRAM в КБ (0 = авто по семейству) | `0` (авто) |

Архитектура принудительно — ARM Cortex-M (`--arm`); указание `--32bit`/
`--64bit` вместе с `app stm32` даст ошибку.

## Сборка

```bash
zenith fw.z              # stm32 -> fw.bin
zenith fw.z -o blinky    # stm32 -> blinky.bin
zenith fw.z -2r         # максимальная оптимизация по размеру (stm32)
```

Точка входа — `func main()` (либо первая функция, если `main` нет).

Для STM32 доступны уровни оптимизации по размеру прошивки:

| Флаг | Уровень | Что делает |
|------|---------|-----------|
| `-0r` / `--0r` | None | Без оптимизации |
| `-1r` / `--1r` | Basic | Сворачивание констант |
| `-2r` / `--2r` | Max | Инлайнинг крошечных функций + сворачивание констант + удаление мёртвых присваиваний |

По умолчанию для STM32 применяется `-2r`; `--no-opt` отключает оптимизатор.

## Встроенные функции

| Функция | Описание |
|---------|----------|
| `gpio_init()` | Настроить используемые пины (вызывается в любом месте; стартовый код уже всё конфигурирует) |
| `gpio_write("PC13", value)` | Записать 0/1 в пин (через BSRR) |
| `gpio_set("PC13")` | Установить пин в 1 |
| `gpio_clear("PC13")` | Установить пин в 0 |
| `gpio_read("PC13")` | Прочитать пин (1/0) |
| `led_on()` / `led_off()` | Включить / выключить бортовой светодиод (`led_pin:`) |
| `led_toggle()` | Переключить бортовой светодиод |
| `print(x)` | Вычислить аргумент и **мигнуть** бортовым светодиодом (экрана на этом таргете нет) |
| `delay_ms(ms)` | Задержка (цикл ожидания, калибруется по `sysclk:`) |
| `uart_init("PA2", baud)` | Настроить бит-банговый UART TX на произвольном пине (baud — константа, напр. `9600`) |
| `uart_write("PA2", byte)` | Отправить один байт |
| `uart_print("PA2", "text")` | Отправить строку |
| `uart_println("PA2", "text")` | Отправить строку с `\r\n` |
| `uart_print_int("PA2", n)` | Отправить целое число в десятичном виде (с `-` для отрицательных) |
| `adc_read("PA0")` | Прочитать АЦП (12 бит). Только линии F1/F4/F7 |
| `abs(x)` | Модуль числа |
| `min(a, b)` / `max(a, b)` | Минимум / максимум |
| `clamp(x, lo, hi)` | Ограничить `x` диапазоном `[lo; hi]` |
| `str_len("text")` | Длина строки в байтах |

Пины задаются строкой вида `"PC13"`, `"PA5"` (можно и без префикса `P`:
`"C13"`, `"A5"`); буква — порт (A–H), число — вывод 0–15.

## Особенности

- `print()` на этом таргете не выводит текст — он переключает светодиод
  (LED мигает при каждом вызове).
- `uart_*` — чисто программный (бит-банговый) передатчик: UART TX можно
  повесить на любой пин. Тактовая частота передаётся через `sysclk:`.
- `uart_print_int` собирает цифры в служебный буфер в SRAM (16 байт,
  хватает на 32-битное число со знаком).
- `adc_read` доступен на линиях F1/F4/F7 (для L4/G0 возвращается ошибка
  компиляции).
- Поля структур занимают по 4 байта каждое (без выравнивания).
- Оптимизатор для STM32 работает в «размерном» режиме (по умолчанию `-2r`);
  уровень задаётся флагами `-0r`/`-1r`/`-2r` (`--no-opt` отключает).
- Глобальные переменные размещаются в SRAM (с `SRAM_BASE = 0x20000000`,
  вверх) и обнуляются стартовым кодом.
- `sram_kb:` переопределяет размер SRAM; авто — по семейству `mcu`
  (F1 — 20 КБ, F4/F7 — 128 КБ, L4 — 128 КБ, G0 — 32 КБ).
  Для QEMU задавайте размер под конкретную машину (например,
  `b-l475e-iot01a` — 96 КБ, `stm32vldiscovery` — 8 КБ).

## IR-бэкенд (экспериментальный, --ir)

Программы `app stm32` можно собрать через ассемблеро-подобный IR-конвейер
(IRGen → IROpt → IRAsm), который включается флагом `--ir`:

```bash
zenith fw.z --ir -o fw    # stm32 через IR -> fw.bin
```

Особенности IR-бэкенда:

- Только 32-битные знаковые целые; при вещественных числах, неподдерживаемых
  встроенных функциях или слишком больших функциях компилятор выводит
  сообщение и автоматически переключается на классический бэкенд (для
  сверхбольших функций — сообщение `branch out of range`, такие функции
  нужно разбивать).
- Вывод `print()`/чисел идёт через периферию **USART2** (адрес `0x40004400`):
  именно её QEMU-машина `stm32vldiscovery` выводит в последовательный порт
  (`-serial file:...`). Строки и числа печатаются с переводом строки `\r\n`.
- Образ: вектор прерываний (SP = конец SRAM, reset → стартовый код),
  стартовый код (тактирование и настройка USART2, копирование начальных
  значений глобальных переменных из флеша в SRAM), рантайм-помощники,
  функции пользователя, пул строк.
- Регистровая машина r0–r11; локальные переменные — в кадре вызываемого
  ([SP + смещение], шаг 8 байт); вызовы — Thumb-2 `bl`, дальние ветвления —
  `movw/movt` + `bx`.
- Проверено в QEMU `stm32vldiscovery` (STM32F100): тест со строками,
  целочисленной арифметикой, рекурсией (`fact`), глобальной переменной и
  делением с остатком печатает
  `Hello from Zenith STM32 IR!`, `7`, `720`, `4`, `11` (по строке каждое).

## Пример (мигание светодиодом)

```zenith
app stm32
mcu: stm32f103
led_pin: PC13
sysclk: 72000000

func main() -> int
    gpio_init()
    while 1
        led_on()
        delay_ms(200)
        led_off()
        delay_ms(200)
    end
    return 0
end
```

## Пример (UART + АЦП)

```zenith
app stm32
mcu: stm32f103
led_pin: PC13
sysclk: 72000000

func main() -> int
    gpio_init()
    uart_init("PA2", 115200)
    uart_println("PA2", "Hello from Zenith!")
    var i: int = 0
    while 1
        uart_print("PA2", "count = ")
        uart_print_int("PA2", i)
        uart_println("PA2", "  adc = ...")
        i = i + 1
        delay_ms(1000)
    end
    return 0
end
```

Совместимость проверена в QEMU на `b-l475e-iot01a` (STM32L475, UART
раскодируется из трейса GPIO как `STM32L4 works\r\n12345 ok\r\n`) и
`stm32vldiscovery` (STM32F100).
