# GUI-программирование

Для GUI нужен заголовок `app gui`. Обязательно указать **категорию**:

```zenith
app gui tool        # приложения-инструменты (редакторы, утилиты)
app gui game        # игры (дополнительные функции rand/getTime/playTone)
```

Оба режима: **рендер по умолчанию Software** (CPU-фреймбуфер, вывод через GDI).

## Жизненный цикл окна

```zenith
app gui tool

func main() -> int
    createWindow(800, 600, "Моё приложение")
    return 0
end
```

| Функция | Сигнатура | Описание |
|---------|-----------|----------|
| `createWindow` | `(w, h, title)` | Создать окно WS_OVERLAPPEDWINDOW, выделить фреймбуфер |
| `present` | `()` | Вывести кадр на экран + обработать сообщения + Sleep(1) |
| `processMessages` | `()` | Обработать очередь сообщений; возвращает **0 при WM_QUIT**, иначе 1 |
| `closeWindow` | `()` | Уничтожить окно (очистка рендера DX11/GDI) |

## Рисование (общие функции)

### drawPixel(x, y, color)

```zenith
drawPixel(100, 50, 0x00FF0000)   # красный пиксель
```

### clear(color)

Заливка всего фреймбуфера цветом.

```zenith
clear(0x00000000)    # чёрный
```

### getKey(vk)

Проверка нажатия клавиши (виртуальный код Win32, `GetAsyncKeyState`).
Возвращает **1**, если клавиша нажата, иначе **0**.

```zenith
if getKey(0x41) == 1     # VK 'A'
    print("Клавиша A нажата")
end
if getKey(0x1B) == 1     # VK_ESCAPE
    closeWindow()
end
```

## Формат цвета

Все функции принимают 32-битный цвет **`0x00RRGGBB`** (8 бит на канал,
как в стандартном BGRA-фреймбуфере):

| Цвет | Код |
|------|-----|
| Красный | `0x00FF0000` |
| Зелёный | `0x0000FF00` |
| Синий | `0x000000FF` |
| Белый | `0x00FFFFFF` |
| Чёрный | `0x00000000` |

## Функции для `app gui tool`

Доступны только при `app gui tool`:

| Функция | Сигнатура | Описание |
|---------|-----------|----------|
| `textWidth` | `(text) -> int` | Ширина текста в пикселях (символ = 6 px) |
| `drawRect` | `(x, y, w, h, color)` | Залитый прямоугольник |
| `drawLine` | `(x1, y1, x2, y2, color)` | Линия (алгоритм Брезенхэма) |
| `drawText` | `(x, y, text, color)` | Текст 5×7-шрифтом |

### Пример: отрисовка рамки

```zenith
drawRect(10, 10, 200, 100, 0x00FF0000)   # рамка
drawLine(10, 120, 210, 220, 0x0000FF00)  # диагональ
drawText(20, 20, "Hello", 0x00FFFFFF)    # текст
```

## Функции для `app gui game`

Доступны только при `app gui game`:

| Функция | Сигнатура | Описание |
|---------|-----------|----------|
| `rand` | `() -> int` | Случайное число (LCG, 0..0x7FFFFFFF) |
| `getTime` | `() -> int` | Время в миллисекундах (`GetTickCount`) |
| `playTone` | `(freq, duration_ms)` | Звуковой сигнал (`Beep`) |

### Пример: игровой цикл

```zenith
app gui game

func main() -> int
    createWindow(640, 480, "Игра")

    var running: int = 1
    while running == 1
        if getKey(0x1B) == 1       # ESC — выход
            closeWindow()
            return 0
        end

        clear(0x00000000)
        var x: int = rand() / 3355443  # 0..0x7FFFFFFF / 3355443 -> 0..639
        var y: int = rand() / 4473924  # -> 0..479
        drawPixel(x, y, 0x00FFFFFF)

        present()
    end
    return 0
end
```

## Указатель на фреймбуфер

Во внутренних глобалах окна хранится указатель на фреймбуфер
(`globals+40`), ширина (`globals+32`) и высота (`globals+36`).
Формат пикселя — 32-битный BGRA. При желании можно писать в него
напрямую через `poke`:

```zenith
var p: int = 0
# p — адрес фреймбуфера (обычно из alloc или известный адрес)
poke(p + (y * 800 + x) * 4, 0x00FFFFFF)
```

## Пример: «горящие точки» (tool)

```zenith
app gui tool

func main() -> int
    createWindow(400, 300, "Точки")
    clear(0x00000000)

    drawPixel(100, 100, 0x00FF0000)
    drawPixel(150, 100, 0x0000FF00)
    drawRect(200, 200, 50, 50, 0x000000FF)

    present()
    return 0
end
```
