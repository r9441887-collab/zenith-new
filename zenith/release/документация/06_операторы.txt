# Операторы

## Арифметика

| Оператор | Описание | Пример |
|----------|----------|--------|
| `+` | Сложение | `5 + 3` → `8` |
| `-` | Вычитание | `10 - 4` → `6` |
| `*` | Умножение | `6 * 7` → `42` |
| `/` | Деление | `10 / 3` → `3` |
| `-` | Унарный минус | `-x` |

> Оператора `%` (остаток от деления) **нет**. Для границ диапазона
> используйте деление и сдвиги: например `rand() / 3355443` даёт `0..639`
> (диапазон `rand()` — `0..0x7FFFFFFF`).

Для `int`: знаковое деление через `idiv`.
Для `float`: `addss`, `subss`, `mulss`, `divss` (SSE).

### Примеры

```zenith
var a: int = 10 + 5       # 15
var b: int = 10 - 3       # 7
var c: int = 4 * 5        # 20
var d: int = 10 / 3       # 3 (целочисленное)
var f: int = -a           # -15

var g: float = 3.14 * 2.0 # 6.28
var h: float = 10.0 / 3.0 # 3.333...
```

## Битовые операции

| Оператор | Описание | Пример |
|----------|----------|--------|
| `&` | AND | `0xF0 & 0x0F` → `0` |
| `\|` | OR | `0xF0 \| 0x0F` → `0xFF` |
| `^` | XOR | `0xFF ^ 0x0F` → `0xF0` |
| `~` | NOT (унарный) | `~0` → `-1` |
| `<<` | Сдвиг влево | `1 << 4` → `16` |
| `>>` | Сдвиг вправо | `16 >> 2` → `4` |

`>>` — **логический** сдвиг: биты, ушедшие за левый край, заполняются
нулём, знак не распространяется. `(-1000) >> 1` даёт
`9223372036854775308`, а не `-500`. Это одно правило для всех платформ —
x86, AArch64 и WebAssembly, — иначе одна и та же программа давала бы разный
результат в зависимости от целевой машины. Деление и остаток здесь, в
отличие от сдвига, знаковые и округляются к нулю, то есть `(-7) / 2` — это
`-3`, а `(-7) % 2` — `-1`.

Шестнадцатеричные литералы: `0x...`. Двоичных (`0b...`) нет.

## Сравнение

| Оператор | Описание |
|----------|----------|
| `==` | Равно |
| `!=` | Не равно |
| `<` | Меньше |
| `>` | Больше |
| `<=` | Меньше или равно |
| `>=` | Больше или равно |

Возвращает `1` (true) или `0` (false).

```zenith
var x: int = 5
print(x == 5)    # 1
print(x > 10)    # 0
print(x <= 5)    # 1
```

### Сравнение float

```zenith
var a: float = 3.14
var b: float = 2.71
if a > b
    print("a больше")
end
```

Использует `ucomiss` + `setcc` инструкции.

## Логические

| Оператор | Описание |
|----------|----------|
| `!` | NOT (унарный) |
| `&&` | AND — **short-circuit** |
| `\|\|` | OR — **short-circuit** |

### Short-circuit

`&&` и `||` используют короткое замыкание: правая часть вычисляется только
при необходимости.

```zenith
# && — если левое false, правое НЕ вычисляется
if a > 0 && b > 0
    print("оба положительные")
end

# || — если левое true, правое НЕ вычисляется
if a > 0 || b > 0
    print("хотя бы один положительный")
end
```

### NOT

```zenith
var flag: bool = true
if !flag
    print("не выполнится")
end
```

## Операторы указателей

| Оператор | Пример | Описание |
|----------|--------|----------|
| `&` | `var p = &x` | Взять адрес переменной (`lea rax, [rbp]`) |
| `*` | `var v = *p` | Разыменование — прочитать значение (`mov rax, [rax]`) |
| `* =` | `*p = val` | Записать значение по указателю |

```zenith
var x: int = 100
var p: ptr<int> = &x       # p = адрес x
var y: int = *p            # y = 100 (прочитали через указатель)
*p = 200                   # x теперь 200
```

## Приоритет операторов

От низкого к высокому:

| Приоритет | Операторы |
|-----------|-----------|
| 1 (низкий) | `\|\|` |
| 2 | `&&` |
| 3 | `\|` |
| 4 | `^` |
| 5 | `&` |
| 6 | `==`, `!=`, `<`, `>`, `<=`, `>=` |
| 7 | `<<`, `>>` |
| 8 | `+`, `-` |
| 9 | `*`, `/` |
| 10 (высокий) | `!`, унарный `-`, `~`, `*` (разыменование), `&` (адрес) |

### Примеры приоритета

```zenith
2 + 3 * 4          # 14 (умножение раньше)
(2 + 3) * 4        # 20 (скобки)

a > 0 && b > 0     # (a > 0) && (b > 0)
!a == b            # (!a) == b
*p + 1             # (*p) + 1
1 << 4 + 1         # 1 << (4+1) = 32 (сложение выше сдвига)
```

## Присваивание

| Оператор | Описание |
|----------|----------|
| `=` | Присваивание |
| `*p = v` | Запись через указатель |

```zenith
x = 10
arr[0] = 42
p.x = 3.14
*p = 999
```

## Доступ к полям и индексация

| Оператор | Описание |
|----------|----------|
| `.` | Доступ к полю структуры |
| `[]` | Индекс массива |
| `->` | Тип возврата (только в сигнатуре функции) |

```zenith
p.x = 5.0           # доступ к полю
var v: int = arr[0]  # индексация
func add(a: int, b: int) -> int   # -> для возврата
```

## Сравнение строк

Нет встроенного сравнения строк. Используйте внешние функции
или сравнивайте посимвольно через указатели.
