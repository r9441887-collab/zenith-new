# Вывод в консоль

Функции `print`, `pause`, `sleep`, `peek`/`poke` доступны в консольных и
GUI-приложениях. В EFI/bare-режиме они не работают (используют Win32 API),
там есть свой `efi_print` / `vga_print`.

## print(value)

Полиморфна: принимает строку ИЛИ целое число (ровно один аргумент).

### Печать строки

```zenith
print("Hello, World!")
```

Выводит строку + `\r\n` (Windows-перевод строки).

### Печать числа

```zenith
print(42)
print(-7)
print(0)
```

Конвертирует число в десятичную строку и выводит через `WriteFile`.

### Печать выражений

```zenith
var x: int = 5 + 3
print(x)           # 8

print(2 * 3 + 1)   # 7
print(100 / 10)    # 10
```

### Важные ограничения

- **Нет** `printFloat()` — float нельзя напечатать напрямую
- **Нет** `printHex()` — hex тоже нельзя
- **Нет** конкатенации строк в выражениях — `"a" + "b"` не работает,
  `print` принимает только один аргумент
- Всегда добавляет `\r\n` в конце

### Решение: печать float

Если нужно напечатать float, масштабируйте и печатайте как int:

```zenith
var piScaled: int = 314
print(piScaled)    # напечатает "314" (означает 3.14)
```

## pause()

```zenith
pause()
```

Выводит "Press any key to continue . . ." и ждёт нажатия клавиши
через `GetStdHandle` + `WriteFile` + `ReadFile`.

## sleep(seconds)

```zenith
sleep(1)          # пауза 1 секунда
sleep(0.5)        # пауза полсекунды (принимает и float)
```

Приостанавливает выполнение на N секунд.
Внутри: конвертация сек → мс (`imul rax, 1000`) и вызов Win32 `Sleep(ms)`.

## alloc / free (динамическая память)

| Функция | Описание |
|---------|----------|
| `alloc(n)` | Выделить `n` байт (bump-аллокатор), вернуть адрес (`int`) |
| `free(addr)` | Освободить блок по адресу |

```zenith
var p: int = alloc(64)    # выделить 64 байта
free(p)                   # освободить
```

## peek / poke (прямой доступ к памяти)

| Функция | Описание |
|---------|----------|
| `peek(addr)` | Прочитать 8 байт (int) по адресу |
| `poke(addr, val)` | Записать 8 байт по адресу |
| `peek8(addr)` / `peek16(addr)` / `peek32(addr)` | Прочитать 1 / 2 / 4 байта |
| `poke8(addr, val)` / `poke16(addr, val)` / `poke32(addr, val)` | Записать 1 / 2 / 4 байта |

```zenith
var p: int = alloc(64)     # выделить 64 байта
poke(p, 42)                # записать 42 по адресу p
var val: int = peek(p)     # прочитать: val = 42

# Смещения:
poke(p + 8, 100)
poke(p + 16, 200)
var a: int = peek(p)       # 42
var b: int = peek(p + 8)   # 100
var c: int = peek(p + 16)  # 200
```

## Полный пример

```zenith
app console

func main() -> int
    print("Запуск программы...")
    sleep(1)

    var x: int = 42
    print("Значение x:")
    print(x)

    print("Вычисление...")
    var result: int = (x * 2 + 10) / 4
    print(result)

    pause()
    return 0
end
```

Вывод:
```
Запуск программы...
Значение x:
42
Вычисление...
23
Press any key to continue . . .
```
