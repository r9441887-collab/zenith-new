# Переменные

## Объявление

Ключевые слова `var`, `let` и `const` объявляют переменную одинаково
(компилятор не различает их на уровне семантики):

```zenith
var x: int = 42            # явный тип + инициализация
var y: int                 # без инициализации (0 по умолчанию)
let health: int = 100      # то же самое что var
const speed: int = 10      # принимается как var
var name: string = "Hero"  # строка
var speed: float = 2.5     # float
```

Если инициализатор не задан, переменная всегда обнуляется.

## Массивы

```zenith
var arr: [10]int           # массив из 10 int
var farr: [5]float         # массив из 5 float

arr[0] = 42                # запись
var val: int = arr[0]      # чтение
```

### Как это работает

Массивы фиксированного размера выделяются целиком на стеке (локальные)
или в .data (глобальные). Индексация вычисляется на этапе компиляции:

| Тип | Формула адреса |
|-----|----------------|
| `int` | `base + index * 8` |
| `float` | `base + index * 4` |

### Пример: сумма элементов

```zenith
app console

func main() -> int
    var arr: [5]int
    arr[0] = 10
    arr[1] = 20
    arr[2] = 30
    arr[3] = 40
    arr[4] = 50

    var sum: int = 0
    var i: int = 0
    while i < 5
        sum = sum + arr[i]
        i = i + 1
    end
    print(sum)    # 150
    return 0
end
```

## Присваивание

```zenith
x = 10                   # простое присваивание
arr[3] = 42              # присваивание элементу массива
player.x = 5.0           # присваивание поля структуры
*p = 200                 # запись через указатель
```

## Область видимости

Переменные, объявленные внутри функции, локальны и живут на стеке в `[rbp-offset]`.
Переменные на верхнем уровне файла — глобальные: выделяются в .data,
обнуляются при старте и доступны из любой функции.

```zenith
app console

var gCounter: int = 0     # глобальная переменная (.data)

func demo()
    var x: int = 10
    if x > 5
        var y: int = 20      # y доступна только в этом блоке
        print(x + y)         # OK
    end
    # print(y)              # ОШИБКА: y не существует здесь
end
```

## Стековая память

Локальные переменные живут на стеке в `[rbp-offset]`:

| Тип | Размер на стеке |
|-----|----------------|
| `int` | 8 байт |
| `float` | 4 байта |
| `bool` | 4 байта |
| `string` | 8 байт (указатель) |
| `vec2` | 8 байт |
| `vec3` | 12 байт |
| `color` | 16 байт |
| массив `[N]T` | N × размер(T) |
| struct | суммарный размер полей (см. 03_структуры.txt) |

### Пример раскладки

```zenith
func example(a: int, b: int) -> int
    var x: int = a + b       # [rbp-16]
    var y: float = 3.14      # [rbp-20]
    var flag: bool = true     # [rbp-24]
    return x
end
```

## Безопасность

Переменные **всегда инициализируются нулями**, если не задано значение.
Нет неинициализированных переменных.
